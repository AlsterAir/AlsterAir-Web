# AlsterAir Website

Responsive, statische Website für GitHub Pages. Keine Build-Tools erforderlich.

## Dateien
- `index.html`: Startseite und Bereiche Flotte, Reiseziele, Über uns, News, Kontakt
- `styles.css`: Design und responsive Layout
- `script.js`: mobiles Menü und Jahreszahl
- `impressum.html`, `datenschutz.html`: Vorlagen mit Platzhaltern, vor Veröffentlichung anpassen
- `robots.txt`, `sitemap.xml`: SEO-Grundlagen, URLs anpassen

## Kostenlos auf GitHub Pages veröffentlichen
1. Melde dich bei GitHub an und erstelle ein neues Repository, z. B. `alsterair-website`.
2. Lade alle Dateien und den Ordner `assets` in das Repository hoch. `index.html` muss im Hauptverzeichnis liegen.
3. Öffne **Settings → Pages**.
4. Bei **Build and deployment** wähle **Deploy from a branch**.
5. Wähle Branch `main` und Ordner `/(root)`, dann **Save**.
6. Warte, bis GitHub Pages die Website veröffentlicht. Die Adresse wird in **Settings → Pages** angezeigt und sieht typischerweise so aus: `https://DEIN-BENUTZER.github.io/alsterair-website/`.

## Vor dem Livegang unbedingt
- In `index.html` `KONTAKTADRESSE-HIER-EINTRAGEN` durch eine echte, funktionierende E-Mail-Adresse ersetzen.
- Impressum und Datenschutzhinweise vollständig und korrekt ausfüllen. Die Dateien sind nur Vorlagen.
- Platzhalter-URLs in `robots.txt` und `sitemap.xml` durch die tatsächliche GitHub-Pages-Adresse ersetzen.
- Den News-Eintrag und das Datum prüfen.
- Nur Aussagen über Flüge, Strecken, Flotte, Preise, Genehmigungen oder Buchbarkeit veröffentlichen, die nachweislich zutreffen.
- Externe Bildquellen/Lizenzen und Datenschutz prüfen. Für mehr Kontrolle können Bilder heruntergeladen werden, sofern Lizenz und Nutzungsbedingungen das erlauben, und lokal eingebunden werden.

## Google
Nach dem Livegang die Website in Google Search Console als URL-Präfix hinzufügen und Eigentümerschaft bestätigen. Die Sitemap-URL einreichen. Indexierung ist nicht garantiert und kann dauern. Keine kostenpflichtige Werbung ist dafür erforderlich.
